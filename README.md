# ⚽ Steam Card Auto-Farmer: SecretBall Cyber Edition

Автоматический бот для умного фарма коллекционных карточек Steam с киберспортивным интерфейсом SecretBall Edition.

---

## 💻 Системные требования для запуска на любом ПК

1. **Операционная система**: Windows 10 / 11 (64-bit).
2. **Python**: версия **3.8 - 3.14** (скачать с [python.org](https://www.python.org/downloads/)).
   > ⚠️ **ВАЖНО**: При установке Python обязательно включите галочку **`Add python.exe to PATH`**!
3. **Клиент Steam**: должен быть запущен на компьютере и авторизован в вашем аккаунте.
4. **SAM (Steam Achievement Manager)**: уже встроен в папку `SAM\` внутри этого проекта — скачивать отдельно ничего не нужно!

---

## 🚀 Быстрый запуск на новом компьютере (в 2 шага)

1. **Шаг 1**: Запустите файл `Install_Requirements.bat` (он автоматически установит библиотеки: `requests`, `beautifulsoup4`, `pillow`).
2. **Шаг 2**: Запустите `Start_Farmer.bat` (или `Start_Farmer.vbs` для абсолютно тихого запуска без консольного окна).

## ⚡ Особенности и логика работы

1. **Параллельный разгон + Фарм**:
   * Если у вас есть игры с наигранными $\ge 2$ часами и игры $< 2$ часов — бот **не ждет 2 часа**, а сразу начинает фармить готовые игры!
   * Одновременно в фоне запускается параллельный разгон всех игр с $< 2$ часами через SAM.
   * Как только любая игра в фоне достигает 120 минут (2.0 ч.), её индивидуальный процесс SAM закрывается, и она сразу переходит в очередь на получение карточек.
   * Если готовых игр нет вообще — бот автоматически запускает Фазу 1 (только разгон) до первого готового тайтла.

2. **Одиночный фарм (Цикл Close & Check)**:
   * Готовые игры фармятся строго по одной (для максимальной скорости выпадения).
   * Каждые 15 минут игра закрывается (так как Steam регистрирует выпадение карточек при закрытии сессии).
   * Бот опрашивает значки, делает повторную контрольную проверку через 20 секунд и перезапускает игру до полного сбора всех доступных карточек.

3. **Защита от зависаний и утечек памяти (Win32 Job Objects)**:
   * Все процессы SAM привязаны к объекту ядра Windows Kernel (`JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`).
   * При закрытии окна (X), нажатии «СТОП» или завершении приложения Windows гарантированно закрывает все дочерние эмуляции.
   * Никаких зависших фоновых процессов в диспетчере задач.
